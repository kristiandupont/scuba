# Contributing to Scuba

Thank you for your interest in contributing to Scuba!

## How to Contribute

### Reporting Bugs
If you find a bug, please open an issue on GitHub. Provide a clear description, steps to reproduce, and expected vs actual behavior.

### Suggesting Enhancements
We welcome suggestions for new features. Please open an issue to discuss the proposal before implementing it.

### Pull Requests
1. Fork the repository.
2. Create a feature branch from `main`.
   `git checkout -b feature/amazing-feature`
3. Commit your changes.
   `git commit -m 'Add some amazing feature'`
4. Push to the branch.
   `git push origin feature/amazing-feature`
5. Create a pull request.

### Coding Standards
Please ensure your code follows the existing style of the project.
